# Custom strategies (`appdimens_custom`)

**Package:** `appdimens_custom` (also re-exported by `appdimens_bom`) · Port of Android `appdimens-dynamic-custom` / KMP `appdimens-kmp-custom`.
See [MODULES.md](MODULES.md) · [Mathematics](MATHEMATICS-AND-CALCULUS.md#custom-strategies) · [API conventions](API-CONVENTIONS.md) · **[Full custom-strategy documentation](custom/README.md)**

The built-in strategies cover most products. When an app (or a design system shared by several apps) needs its **own** growth law, this package lets you write it. The simplest form is one line of typed Dart; the full form is a configuration that loads from JSON on every AppDimens platform (Android, KMP, iOS, React Native, Web, Games, .NET) with the same numbers.

```dart
import 'package:appdimens_custom/appdimens_custom.dart';

// Factor: the number that multiplies every value
final product = customScaleStrategy((s) => s.clamp(s.width / 360, 0.85, 1.80));
// Formula: the final value (base = the 16 in 16.cdpWith(hud))
final hud = scalingFormulaOf((s) => s.base * s.pow(s.sw / 360, 0.8));
// Text, for JSON and remote config
final remote = scalingFormula('base * pow(sw / 360, 0.8)');
// Full configuration with rules
final brand = ScalingStrategy.define('brand',
    reference: ReferenceScreen(width: 360, height: 640),
    curve: ScalingCurve.power(0.8),
    minFactor: 0.85, maxFactor: 1.6,
    rules: [ScalingRule.on({DeviceClass.tablet, DeviceClass.desktop},
        ScalingPatch(curve: ScalingCurve.logarithmic(0.4)))]);

Padding(padding: EdgeInsets.all(16.cdpWith(product)));          // dp
Text('Score', style: TextStyle(fontSize: 18.cspWith(hud)));     // fontSize (TextScaler applied by Flutter)
SizedBox(width: context.cdp(48, brand));                        // also subscribes to MediaQuery
16.cdpFormula('base * (sw / 360)');                             // inline text formula
```

## When to use it

- A design system shared by several apps that needs one growth law everywhere.
- A product whose UI must behave differently per device class: TV, watch, car, tablet, desktop.
- Remote-config or A/B experiments on scaling, by shipping a new JSON.
- Built-ins that are close but need a different reference frame, exponent or bounds.

## Trade-offs

- Strategies are plain Dart objects created at runtime. Keep them in one place (a `strategies.dart` file or the JSON document).
- Code functions cannot be exported to JSON; their text equivalents can.
- Dart has no overloading: text formulas use `cdpFormula` / `cspFormula`, while `cdpWith` takes a strategy or an id.
- The aspect-ratio correction always uses the satellite law (`× (1 + k·ln(AR/1.78))`).
- `packages/appdimens_custom/test/custom-strategy-fixture.json` (540 cases, generated by the Kotlin reference engine) runs in CI with a relative tolerance of 1e-4.
