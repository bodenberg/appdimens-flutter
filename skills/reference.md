## Package layout

Paths at Git ref **`main`**. Full graph: [MODULES.md](https://github.com/bodenberg/appdimens-flutter/blob/main/DOCUMENTATION/MODULES.md) · [library-map.md](library-map.md).

- **`packages/appdimens/lib/src/common`** — `DpQualifier`, `Inverter`, `DimensOrientation`, `UiModeType`, `UnitType`.
- **`packages/appdimens/lib/src/core`** — `ScreenConfiguration` (immutable window config), `DimenMetrics` (per-window snapshot, eager factors), `DimenCache` (snapshot-partitioned; bypass rules; `AppDimensScope` fast-lane slot), `DimenCalculationPlumbing`, `DimenScaledEngine`, `DesignScaleConstants`, resize math (`ResizeMath`, `ResizeBound`, `AutoResizePercentBasis`).
- **`packages/appdimens/lib/src/scaled`** — `num.sdp/hdp/wdp` extensions + facilitators + Plain pairs, `ssp/hsp/wsp` + `sem/hem/wem`, `DimenSdp`/`DimenSsp` facades, explicit-context extensions, `DimenScaled`/`ScaledSp` builders.
- **`packages/appdimens/lib/src/flutter`** — `AppDimensApp`, `AppDimensScopeBinder`, `AppDimensProvider`, `publishAppDimensContext`.
- **`packages/appdimens_<strategy>`** — satellites: `<strategy>_engine.dart` + `<strategy>_extensions.dart`; generated by [`scripts/generate_satellites.py`](https://github.com/bodenberg/appdimens-flutter/blob/main/scripts/generate_satellites.py).
- **`packages/appdimens_resize`** — constraint resize widgets and range search (not a scaling curve).

Regenerate package metadata with [`scripts/generate_package_docs.py`](https://github.com/bodenberg/appdimens-flutter/blob/main/scripts/generate_package_docs.py); publish order in [PUBLISHING.md](https://github.com/bodenberg/appdimens-flutter/blob/main/PUBLISHING.md).

## Internal `CalcType` (debug / cache tagging)

Maps to package families: auto, diagonal, fill, fit, fluid, interpolated, logarithmic, percent, perimeter, power, resize, scaled, unities, aspectRatio, density — see [`dimen_cache.dart`](https://github.com/bodenberg/appdimens-flutter/blob/main/packages/appdimens/lib/src/core/dimen_cache.dart). End users think in **strategy names** and imports, not this enum.
