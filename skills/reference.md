## Package layout

Paths at Git ref **`main`**. Full graph: [MODULES.md](https://github.com/bodenberg/appdimens-flutter/blob/main/DOCUMENTATION/MODULES.md) · [library-map.md](library-map.md).

- **`packages/appdimens_flutter/lib/src/common`** — `DpQualifier`, `Inverter`, `DimensOrientation`, `UiModeType`, `UnitType`.
- **`packages/appdimens_flutter/lib/src/core`** — `ScreenConfiguration` (immutable window config), `DimenMetrics` (per-window snapshot, eager factors), `DimenCache` (snapshot-partitioned; bypass rules; `AppDimensScope` fast-lane slot), `DimenCalculationPlumbing`, `DimenScaledEngine`, `DesignScaleConstants`, resize math (`ResizeMath`, `ResizeBound`, `AutoResizePercentBasis`).
- **`packages/appdimens_flutter/lib/src/scaled`** — `num.sdp/hdp/wdp` extensions + facilitators + Plain pairs, `ssp/hsp/wsp` + `sem/hem/wem`, `DimenSdp`/`DimenSsp` facades, explicit-context extensions, `DimenScaled`/`ScaledSp` builders.
- **`packages/appdimens_flutter/lib/src/flutter`** — `AppDimensApp`, `AppDimensScopeBinder`, `AppDimensProvider`, `publishAppDimensContext`.
- **`packages/appdimens_<strategy>`** — satellites: `<strategy>_engine.dart` + `<strategy>_extensions.dart`; generated by [`scripts/generate_satellites.py`](https://github.com/bodenberg/appdimens-flutter/blob/main/scripts/generate_satellites.py).
- **`packages/appdimens_resize`** — constraint resize widgets and range search (not a scaling curve).

Regenerate package metadata with [`scripts/generate_package_docs.py`](https://github.com/bodenberg/appdimens-flutter/blob/main/scripts/generate_package_docs.py); publish order in [PUBLISHING.md](https://github.com/bodenberg/appdimens-flutter/blob/main/PUBLISHING.md).

## Custom strategies (`appdimens_custom`)

`ScalingStrategy.define(id, reference:, axis:, curve:, minFactor:, maxFactor:, minValue:, maxValue:, aspectRatio:, fontScale:, formula:, rules: [ScalingRule.on({DeviceClass.tablet}, ScalingPatch(...))])` · free-form `ScalingCurve.expression('pow(ratio, 0.8) * (tablet ? 0.9 : 1)')` / `formula: 'base * pow(sw / 360, 0.7) + 2'` (variables `sw width height shortSide longSide diagonal perimeter aspectRatio density fontScale`, flags `landscape portrait multiWindow phone tablet desktop tv watch car vr`, `ratio axis ref refWidth refHeight`, `base scaled factor`; functions `min max clamp pow sqrt ln log log10 log2 exp abs sign floor ceil round lerp step smoothstep`) · `ScalingStrategies.loadJson(json)` / `defaultStrategy` · `16.cdp`, `16.cdpWith(s)`, `14.csp`, `context.cdp(16)`, `ScalingStrategyScope`, `s.explain()` — [custom.md](../DOCUMENTATION/custom.md)

Simplest form: `16.cdpFormula('base * pow(sw / 360, 0.8)')` · `cspFormula` · `context.cdpFormula(16, '…')` · `scalingFormula('…', id:)` · `ScalingStrategies.formula('…')` · typed code `scalingFormulaOf((s) => s.base * s.pow(s.sw / 360, 0.8))` (`FormulaScope`) · `customScaleStrategy((s) => s.clamp(s.width / 360, 0.85, 1.8), id:)` (`ScreenScope`, factor, once per window); `base * (…)` formulas are screen-only (one multiply per value). Full guides: [DOCUMENTATION/custom/](../DOCUMENTATION/custom/README.md); agent notes: [custom.md](custom.md).
